# 이차함수의 꼭짓점과 대칭축

- 날짜: 2026-09-25
- 상태: 오늘의 학습 자료·연습 과제
- 범위: 편입수학 기초수학

## 1. 꼭짓점형 읽기

이차함수가 다음 형태라면 그래프의 핵심 정보를 바로 읽을 수 있다.

\[
y=a(x-p)^2+q
\]

- 꼭짓점: \((p,q)\)
- 대칭축: \(x=p\)
- \(a>0\): 아래가 아니라 위로 열린다.
- \(a<0\): 아래로 열린다.
- \(|a|\)가 커질수록 그래프 폭이 좁아진다.

괄호 안이 `x-p`이므로 꼭짓점의 x좌표 부호를 반대로 읽지 않도록 주의한다.

## 2. 일반형을 꼭짓점형으로 바꾸기

예제로 다음 함수를 완전제곱식으로 바꿔보자.

\[
y=x^2-6x+5
\]

먼저 x가 포함된 항만 완전제곱식으로 만든다.

\[
x^2-6x=(x-3)^2-9
\]

따라서

\[
y=(x-3)^2-9+5=(x-3)^2-4
\]

꼭짓점은 \((3,-4)\), 대칭축은 \(x=3\)이다. 최고차항의 계수가
양수이므로 위로 열린다.

## 3. 계수가 1이 아닐 때

\[
y=2x^2+8x+3
\]

먼저 앞의 2를 묶는다.

\[
y=2(x^2+4x)+3
\]

괄호 안을 완전제곱식으로 바꾼다.

\[
x^2+4x=(x+2)^2-4
\]

따라서

\[
y=2\{(x+2)^2-4\}+3=2(x+2)^2-5
\]

꼭짓점은 \((-2,-5)\), 대칭축은 \(x=-2\)이다.

## 핵심 질문

1. \(y=a(x-p)^2+q\)에서 꼭짓점과 대칭축은 무엇인가?
2. \(a\)의 부호는 그래프 방향을 어떻게 바꾸는가?
3. 일반형에서 완전제곱식을 만드는 이유는 무엇인가?
4. 최고차항의 계수가 1이 아니면 어떤 항을 먼저 묶어야 하는가?

## 연습문제

다음을 꼭짓점형으로 바꾸고 꼭짓점·대칭축·그래프 방향을 구한다.

1. \(y=x^2+4x+1\)
2. \(y=x^2-8x+10\)
3. \(y=-x^2+6x-5\)
4. \(y=2x^2-12x+7\)
5. \(y=3x^2+6x-2\)
6. \(y=-2x^2-8x+1\)

## 복습 방법

1. 1~3번을 해설 없이 푼다.
2. 틀린 문제는 완전제곱식으로 바꾸는 한 줄을 다시 작성한다.
3. 4~6번은 최고차항의 계수를 먼저 묶고 푼다.
4. 마지막으로 문제 하나를 좌표평면에 직접 그린다.
