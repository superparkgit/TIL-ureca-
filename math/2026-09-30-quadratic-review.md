# 이차방정식 종합 복습

> 상태: 오늘의 학습 자료 및 손풀이 과제

## 풀이 순서

이차방정식을 만나면 다음 순서를 습관으로 만든다.

1. 모든 항을 한쪽으로 옮겨 `ax² + bx + c = 0`으로 정리한다.
2. `a`, `b`, `c`의 부호까지 정확히 적는다.
3. 인수분해가 가능한지 먼저 살펴본다.
4. 어렵다면 판별식 `D = b² - 4ac`와 근의 공식을 사용한다.
5. 구한 근을 원래 식에 대입하거나 근과 계수의 관계로 검산한다.

## 예제

`2x² - 5x - 3 = 0`

곱이 `-6`, 합이 `-5`가 되는 두 수는 `-6`과 `1`이다.

```text
2x² - 6x + x - 3 = 0
2x(x - 3) + 1(x - 3) = 0
(2x + 1)(x - 3) = 0
```

따라서 `x = -1/2` 또는 `x = 3`이다. 두 근의 합은 `5/2 = -b/a`, 곱은 `-3/2 = c/a`이므로 검산도 맞는다.

## 손풀이 6문제

1. `x² - 7x + 12 = 0`
2. `2x² + x - 6 = 0`
3. `3x² - 4x + 2 = 0`의 실근 개수를 판별하라.
4. `x² + 6x + 5 = 2x + 1`
5. 두 근의 합이 4이고 곱이 -5인 최고차항 계수가 1인 이차방정식을 만들어라.
6. `x² - 2(k + 1)x + k² = 0`이 중근을 가질 때 `k`를 구하라.

오늘은 1~4번을 필수로 풀고, 5~6번은 선택으로 둔다. 각 답 옆에 인수분해·판별식·근의 공식 중 어떤 방법을 썼는지 표시한다.

## 핵심 질문

1. 방정식을 `= 0` 꼴로 먼저 정리해야 하는 이유는 무엇인가?
2. `D < 0`, `D = 0`, `D > 0`은 실근의 개수와 어떻게 연결되는가?
3. 근의 합과 곱으로 계산 실수를 어떻게 찾을 수 있는가?

## 복습 체크

- [ ] `a`, `b`, `c`를 부호까지 정확히 찾는다.
- [ ] 인수분해가 안 될 때 근의 공식을 적용한다.
- [ ] 최소 한 가지 방법으로 답을 검산한다.
- [ ] 틀린 문제는 계산 실수와 개념 실수 중 하나로 분류한다.
