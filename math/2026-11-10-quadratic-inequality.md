# 오늘의 학습 자료: 포물선에서 부등식으로 읽기

완료 보고가 없으므로 기초수학의 이차함수 복습을 유지한다. 미적분 진도로 넘어가지 않는다.

## 개념과 직접 만든 예제
`(x-2)^2 ≤ 9`는 x와 2 사이의 거리가 3 이하라는 뜻이다. 따라서 `-3 ≤ x-2 ≤ 3`, 즉 `-1 ≤ x ≤ 5`다. 그래프에서는 포물선 `y=(x-2)^2`가 수평선 `y=9` 아래 또는 같은 부분이다. 등호 포함 여부에 따라 경계점 포함도 달라진다.

## 손풀이 3문제
1. `(x+1)^2 ≤ 4`의 해를 구하고 수직선에 표시한다.
2. `(x-3)^2 > 1`의 해를 구한다. 두 경계점 사이인지 바깥인지 설명한다.
3. `(x-2)^2 ≤ -1`의 실수 해가 있는지 제곱의 성질로 설명한다.

핵심 질문: 제곱근을 취할 때 왜 양쪽 부호를 생각해야 할까? `>`와 `≥`에서 경계가 어떻게 달라질까?

복습: 어제의 포물선·수평선 교점, 완전제곱식, 경계값 대입. 오늘은 세 문제 중 첫 두 문제를 필수로 하고 세 번째는 선택으로 한다.
