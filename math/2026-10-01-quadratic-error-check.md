# 이차방정식 오답 점검: 부호·판별식·검산

> 상태: 오늘의 학습 자료 및 손풀이 과제

새 범위로 넘어가기 전에 이차방정식에서 자주 생기는 실수를 유형별로 점검한다.

## 실수 1: 표준형으로 정리하지 않기

x² + 5 = 4x에서 바로 a = 1, b = 4, c = 5로 읽으면 b의 부호가 틀린다.

x² - 4x + 5 = 0으로 고친 뒤 a = 1, b = -4, c = 5로 읽는다. 항상 모든 항을 한쪽으로 옮긴 뒤 계수를 찾는다.

## 실수 2: 판별식에서 괄호 생략하기

b가 음수일 때는 반드시 괄호를 쓴다. a = 2, b = -3, c = 4라면 D = (-3)² - 4·2·4이다. 대입 단계에서 괄호를 습관화한다.

## 실수 3: 근의 공식 분모를 전체에 적용하지 않기

근의 공식 x = (-b ± √D) / (2a)에서 분모 2a는 분자의 전체에 적용된다. 분자와 분모를 각각 한 줄에 적으면 계산 실수를 줄일 수 있다.

## 실수 4: 답을 구하고 끝내기

근이 α, β라면 α + β = -b/a와 αβ = c/a를 확인한다. 가능하면 원래 식에 한 근을 직접 대입해 0이 되는지도 확인한다.

## 손풀이 5문제

1. x² + 3 = 4x
2. 2x² - 3x + 4 = 0의 실근 개수를 구하라.
3. 3x² + 7x - 6 = 0
4. 2x(x - 1) = x + 3
5. 두 근이 -2, 5이고 최고차항 계수가 1인 이차방정식을 만들어라.

각 문제 옆에 표준형, 계수, 선택한 풀이법, 검산 네 항목을 적는다. 오늘은 1~3번을 필수로, 4~5번을 선택으로 푼다.

## 핵심 질문

1. 항을 이항하면 계수의 부호가 왜 바뀌는가?
2. 판별식이 음수일 때 실수 범위에서 답이 없는 이유는 무엇인가?
3. 근과 계수의 관계로 어떤 계산 오류를 찾을 수 있는가?

## 복습 체크

- [ ] 방정식을 우변이 0인 표준형으로 먼저 바꾼다.
- [ ] 음수 계수를 괄호와 함께 공식에 대입한다.
- [ ] 근의 공식에서 분모를 분자 전체에 적용한다.
- [ ] 답을 근의 합·곱 또는 직접 대입으로 검산한다.
