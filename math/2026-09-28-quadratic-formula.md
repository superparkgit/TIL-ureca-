# 근의 공식과 검산

- 날짜: 2026-09-28
- 상태: 오늘의 학습 자료·연습 과제
- 범위: 편입수학 기초수학

## 1. 근의 공식

이차방정식

\[
ax^2+bx+c=0 \quad (a\ne0)
\]

의 근은 다음 공식으로 구한다.

\[
x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}
\]

근의 공식을 적용하기 전에 식을 반드시 `= 0` 형태로 정리하고 `a`, `b`,
`c`의 부호를 포함해 표시한다.

## 2. 판별식과 연결하기

제곱근 안의 `b²-4ac`가 판별식 `D`다.

- `D > 0`: 서로 다른 두 실근
- `D = 0`: 같은 값의 중근
- `D < 0`: 실수 범위에서는 근이 없음

따라서 공식을 끝까지 계산하기 전에 판별식으로 결과 형태를 예상할 수 있다.

## 3. 예제

\[
2x^2-3x-2=0
\]

계수는 `a=2`, `b=-3`, `c=-2`다.

\[
D=(-3)^2-4\cdot2\cdot(-2)=9+16=25
\]

\[
x=\frac{-(-3)\pm\sqrt{25}}{2\cdot2}
=\frac{3\pm5}{4}
\]

따라서 근은 `2`, `-1/2`다.

## 4. 검산

구한 근을 원래 방정식에 대입해 좌변이 0이 되는지 확인한다.

- `x=2`: `2(2²)-3(2)-2 = 8-6-2 = 0`
- `x=-1/2`: 원래 식에 대입하면 역시 0이 된다.

검산은 부호 실수와 분모 `2a`를 잘못 계산한 오류를 찾는 가장 직접적인 방법이다.

## 자주 하는 실수

- `-b`에 `b`의 부호를 다시 적용하지 않는다.
- 분모를 `2a`가 아니라 `2`로만 적는다.
- `b²` 계산에서 음수의 괄호를 생략한다.
- 방정식을 `= 0`으로 정리하기 전에 계수를 읽는다.

## 핵심 질문

1. 근의 공식을 쓰기 전에 식을 어떤 형태로 정리해야 하는가?
2. `b=-3`이면 `-b`와 `b²`는 각각 얼마인가?
3. 판별식이 음수라면 실수 범위에서 어떤 결론을 내리는가?
4. 구한 근을 가장 간단하게 검산하는 방법은 무엇인가?

## 연습문제

근의 공식으로 풀고 원래 식에 대입해 검산한다.

1. \(x^2-3x-4=0\)
2. \(x^2+4x+1=0\)
3. \(2x^2+5x-3=0\)
4. \(3x^2-2x-1=0\)
5. \(4x^2+4x+1=0\)
6. \(2x^2+2x+5=0\)

## 복습 방법

1. 각 문제에서 `a`, `b`, `c`를 먼저 적는다.
2. 판별식으로 실근의 개수를 예상한다.
3. 근의 공식을 적용한다.
4. 실근이 있다면 한 근 이상을 원래 식에 대입한다.
