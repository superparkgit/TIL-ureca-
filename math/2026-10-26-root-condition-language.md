# 실근 조건을 부등식으로 옮기기

> 오늘의 기초수학 자료·손풀이 과제. 기존 판별식 범위를 복습한다.

## 개념과 직접 만든 예제

실근이 있다 → D≥0, 서로 다른 두 실근 → D>0, 중근 → D=0, 실근이 없다 → D<0이다. 문제 문장에서 등호 포함 여부를 먼저 결정한다.

x²+2x+k=0에서 D=4-4k다. 실근이 없으려면 k>1이다. k=1은 중근이므로 실근 없음에 포함되지 않는다.

## 손풀이 3문제

1. x²-6x+k=0이 실근이 없을 k의 범위를 구한다.
2. 같은 식이 실근을 가질 범위를 구하고 1번과 합쳐 실수 전체를 나누는지 확인한다.
3. 2x²+2x+k=0이 중근을 가질 k와 근을 구한다.

필수 1~2번, 선택 3번. 어제 판별식 경계값을 원래 식에 대입하는 항목만 복습한다.

## 핵심 질문과 복습

- 중근도 실근에 포함되는가?
- 실근 존재와 부재의 경계는 어떤 경우인가?
- [ ] 문장을 판별식 부등식으로 옮긴다.
- [ ] 음수로 나눌 때 부등호를 바꾼다.
- [ ] 경계값의 중근 여부를 확인한다.
