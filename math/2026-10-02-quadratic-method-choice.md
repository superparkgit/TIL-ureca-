# 이차방정식 풀이법 선택하기

> 상태: 오늘의 학습 자료 및 손풀이 과제

이차방정식은 무조건 한 방법만 쓰기보다 식의 모양에 맞는 풀이법을 고르면 계산이 짧아지고 실수도 줄어든다.

## 1. 공통인수로 묶기

x² - 5x = 0처럼 모든 항에 x가 있다면 x(x - 5) = 0으로 묶는다. 곱이 0이면 적어도 한 인수가 0이라는 성질을 사용한다.

## 2. 인수분해

x² - 7x + 12 = 0처럼 곱과 합을 쉽게 찾을 수 있다면 (x - 3)(x - 4) = 0으로 푼다.

## 3. 제곱근 이용

(x - 2)² = 9처럼 완전제곱식이 이미 보이면 x - 2 = ±3으로 푸는 것이 가장 짧다. ±를 빠뜨리지 않는다.

## 4. 근의 공식

인수분해가 바로 보이지 않으면 근의 공식을 사용한다. 먼저 표준형으로 정리하고 a, b, c를 부호와 함께 적는다.

## 선택 순서

1. 우변을 0으로 정리한다.
2. 공통인수가 있는지 본다.
3. 인수분해 또는 완전제곱 형태가 보이는지 확인한다.
4. 보이지 않으면 판별식과 근의 공식을 사용한다.
5. 근의 합과 곱 또는 대입으로 검산한다.

## 손풀이 6문제

1. x² - 6x = 0
2. x² - 9x + 20 = 0
3. (x + 1)² = 16
4. 2x² + x - 4 = 0
5. 3x² = 12x
6. x² + 4x + 4 = 0

오늘은 1~4번을 필수로 푼다. 계산 전에 선택한 풀이법과 선택 이유를 한 줄로 적고, 답을 구한 뒤 검산한다. 5~6번은 선택 복습이다.

## 핵심 질문

1. 인수분해가 보이는 문제에도 근의 공식을 써도 되는가? 효율 차이는 무엇인가?
2. 제곱근을 취할 때 ±가 필요한 이유는 무엇인가?
3. 중근이 나오는 식은 인수분해 형태에서 어떻게 보이는가?

## 복습 체크

- [ ] 표준형으로 먼저 정리한다.
- [ ] 식의 모양을 보고 풀이법을 선택한다.
- [ ] 제곱근 풀이에서 ±를 적는다.
- [ ] 답을 원래 식에 대입하거나 근의 합·곱으로 확인한다.
