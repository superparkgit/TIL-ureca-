# 오늘의 연습 과제 · 절댓값 기초 점검

|x−a|는 a와 x 사이 거리다. 예를 들어 |x+2| ≤ 3은 −5 ≤ x ≤ 1이다. 가운데 값 −2를 대입하면 0이므로 구간 내부가 해임을 확인할 수 있다.

핵심 질문. 해를 구한 뒤 끝점과 내부 점을 각각 대입하면 어떤 실수를 발견할 수 있을까?

손풀이 2문제

1. |2x+4| < 6의 해를 구하고 끝점 두 개와 내부 점을 검산한다.
2. |x−1|=−2의 실수 해가 있는지 거리의 성질로 설명한다.

복습. 중심, 계수 분리, 음수 경계, 등호 유무를 점검한다. 직접 풀이 완료 보고 전까지 기초수학 복습을 유지한다.
