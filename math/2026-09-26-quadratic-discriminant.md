# 이차방정식의 판별식

- 날짜: 2026-09-26
- 상태: 오늘의 학습 자료·연습 과제
- 범위: 편입수학 기초수학

## 1. 판별식의 의미

이차방정식

\[
ax^2+bx+c=0 \quad (a\ne0)
\]

의 근의 공식은 다음과 같다.

\[
x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}
\]

제곱근 안의 값

\[
D=b^2-4ac
\]

를 판별식이라고 한다. `D`의 부호를 확인하면 실제로 근을 끝까지 계산하지
않아도 실수 범위에서 근의 개수를 판단할 수 있다.

## 2. 판별식과 실근의 개수

| 판별식 | 실근 | 그래프 해석 |
| --- | --- | --- |
| \(D>0\) | 서로 다른 두 실근 | x축과 두 점에서 만난다. |
| \(D=0\) | 중근 하나 | x축에 한 점에서 접한다. |
| \(D<0\) | 실근 없음 | x축과 만나지 않는다. |

판별식은 방정식의 근과 이차함수 그래프의 x절편을 연결한다.

## 3. 예제

### 서로 다른 두 실근

\[
x^2-5x+6=0
\]

\[
D=(-5)^2-4\cdot1\cdot6=25-24=1>0
\]

따라서 서로 다른 두 실근을 갖는다.

### 중근

\[
x^2-4x+4=0
\]

\[
D=(-4)^2-4\cdot1\cdot4=0
\]

따라서 중근 하나를 갖고 그래프는 x축에 접한다.

## 핵심 질문

1. 판별식은 근의 공식에서 어느 부분인가?
2. `D=0`일 때 `±`가 두 근을 만들지 못하는 이유는 무엇인가?
3. 실근의 개수와 이차함수의 x절편 개수는 어떻게 연결되는가?
4. `b`가 음수일 때 `b²` 계산에서 주의할 점은 무엇인가?

## 연습문제

근을 직접 구하기 전에 판별식으로 실근의 개수를 판단한다.

1. \(x^2-7x+10=0\)
2. \(x^2+6x+9=0\)
3. \(x^2+2x+5=0\)
4. \(2x^2-3x-2=0\)
5. \(3x^2+6x+4=0\)
6. \(-x^2+4x-4=0\)

## 복습 방법

1. 각 문제에서 `a`, `b`, `c`를 먼저 표시한다.
2. 판별식을 계산하고 부호만으로 근의 개수를 적는다.
3. 1~3번은 근의 공식까지 계산해 판별 결과를 확인한다.
4. 틀린 문제는 부호와 제곱 계산 과정을 한 줄씩 다시 쓴다.
