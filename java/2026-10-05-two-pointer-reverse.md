# 두 포인터로 배열 구간 뒤집기

> 상태: 오늘의 학습 자료 및 연습 과제

## 핵심 원리

구간을 뒤집으려면 가장 왼쪽 값과 가장 오른쪽 값을 교환하고, 두 위치를 한 칸씩 가운데로 이동하면 된다. 이 과정을 두 위치가 만나거나 엇갈릴 때까지 반복한다.

예를 들어 [1, 2, 3, 4, 5] 전체를 뒤집는다.

1. 1과 5를 교환해 [5, 2, 3, 4, 1]
2. 2와 4를 교환해 [5, 4, 3, 2, 1]
3. 양쪽 위치가 가운데 3에서 만나므로 종료

## 반복 조건

left가 right보다 작은 동안만 교환한다. 두 값이 같으면 가운데 원소 하나를 가리키므로 교환해도 결과가 바뀌지 않는다. 조건을 작거나 같음으로 써도 답은 같지만 불필요한 연산이 생긴다.

## 포인터 이동

한 번 교환한 뒤에는 left를 1 증가시키고 right를 1 감소시킨다. 한쪽만 움직이면 이미 처리한 값이 다시 교환되거나 반복문이 끝나지 않을 수 있다.

## 부분 구간의 경계

배열 전체가 아니라 [start, end]만 뒤집는다면 start보다 앞과 end보다 뒤의 값은 절대 수정하지 않는다. 테스트할 때 범위 안의 역순뿐 아니라 범위 밖 값의 보존도 확인한다.

## 핵심 질문

1. 홀수 길이 구간의 가운데 값은 왜 교환하지 않아도 되는가?
2. 같은 구간을 두 번 뒤집으면 원래 배열이 되는 이유는 무엇인가?
3. left 증가나 right 감소를 빠뜨리면 어떤 문제가 생기는가?

## 직접 연습

1. [1, 2, 3, 4, 5, 6]의 2~5번 위치를 뒤집는다.
2. 길이 1인 구간과 길이 2인 구간을 각각 뒤집는다.
3. 문자열을 문자 배열로 바꿔 같은 방식으로 뒤집는다.

## 복습 체크

- [ ] 양끝 교환과 포인터 이동을 보지 않고 작성한다.
- [ ] 홀수·짝수 길이 구간의 종료 상태를 손으로 그린다.
- [ ] 부분 구간 밖의 값이 유지되는지 확인한다.
- [ ] 같은 구간을 두 번 뒤집는 테스트를 만든다.
