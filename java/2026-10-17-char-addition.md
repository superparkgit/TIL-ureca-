# char 덧셈과 문자열 연결 구별하기

> 오늘의 학습 자료·연습 과제. 사용자 학습 완료 기록은 아니다.

## 개념과 직접 만든 예제

Java의 char는 산술 연산에서 int로 승격될 수 있다. 'A' + 'B'는 문자열 AB가 아니라 정수 131이다. 두 문자를 연결하려면 StringBuilder에 각각 append하거나 문자열 피연산자를 포함해야 한다.

StringBuilder result = new StringBuilder(); 이후 result.append('A'); result.append('B');를 실행하면 결과는 AB다.

길이가 1인 단어의 첫 인덱스와 마지막 인덱스는 모두 0이다. 첫·마지막 문자를 둘 다 출력하라는 요구라면 두 번 출력하는 것이 맞다.

## 핵심 질문

1. char 두 개를 더하면 왜 문자열이 되지 않는가?
2. 길이 1인 문자열에 charAt(1)을 호출하면 어떻게 되는가?
3. 빈 문자열도 허용되는 서비스라면 접근 전에 무엇을 확인할까?

## 직접 연습과 복습

- 'C'+'D'와 문자열 연결의 결과·타입을 예측하고 실행한다.
- 한 글자와 여러 글자에서 첫·마지막 문자를 출력한다.
- [ ] 문자 덧셈과 연결을 구분한다.
- [ ] 마지막 인덱스를 length()-1로 계산한다.
- [ ] 길이 1의 출력 요구를 확인한다.
