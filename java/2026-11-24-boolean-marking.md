# 오늘의 학습 자료 · boolean 표시와 중복 제거

boolean 배열의 초기 원소는 false다. 어떤 위치를 처음 처리할 때 true로 바꾸고 개수를 증가시키면 같은 위치를 다시 방문해도 중복 집계를 피할 수 있다.

직접 만든 예제에서 방문 순서가 [2, 2, 4]이면 처음 표시하는 인덱스는 2와 4이므로 개수는 2다.

핵심 질문. 표시하기 전에 검사해야 할까, 표시한 뒤 검사해야 할까?

손풀이. 3×3 격자에서 첫 행 전체와 첫 열 전체를 표시할 때 처음 방문한 칸 수를 구한다. 중첩되는 모서리를 따로 확인한다.

복습. 배열 초기값, 유효 인덱스, 반열린 구간의 반복 횟수를 설명한다.
