# 집합 원소를 저장하지 않고 개수 구하기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

A={1,2,4}, B={2,3}의 공통 원소는 2 하나다. 크기 합 5에서 공통 기여 2를 빼면 한쪽에만 있는 원소 {1,3,4}의 개수 3을 얻는다.

필요한 출력이 개수뿐이면 결과 목록을 만들지 않고 집계값으로 계산할 수 있다. 입력 집합에 내부 중복이 없다는 조건을 확인해야 원래 입력 개수를 집합 크기로 사용할 수 있다.

## 핵심 질문

1. 공통 원소 수를 한 번만 빼면 어떤 집합의 크기가 되는가?
2. 결과 정렬이 필요 없는 이유는 무엇인가?
3. 일반 목록에 중복이 있다면 크기를 어떻게 구해야 하는가?

## 직접 연습과 복습

- A={2,5,7}, B={5,7,9}의 교집합·합집합·대칭 차집합 크기를 구한다.
- 같은 집합과 서로 겹치지 않는 집합을 테스트한다.
- [ ] 요구 출력이 원소인지 개수인지 확인한다.
- [ ] 내부 중복 조건을 확인한다.
- [ ] 공통 원소가 두 번 집계되는 이유를 설명한다.
