# 문자 배열 정렬과 역순 출력

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

문자열 3021을 toCharArray로 바꾸고 Arrays.sort를 호출하면 문자 배열은 0123 순서가 된다. 뒤에서 앞으로 append하면 3210이다.

숫자 문자만 있을 때 문자 코드 순서가 숫자 크기와 일치한다. 일반 문자열의 문자 코드 정렬은 언어별 사전 순서나 자연스러운 숫자 순서를 보장하지 않는다.

Arrays.sort는 배열을 직접 변경한다. 역순 출력은 배열을 다시 뒤집지 않고 인덱스를 감소시키는 방식으로도 가능하다.

## 핵심 질문

1. 마지막 인덱스가 length가 아닌 length-1인 이유는 무엇인가?
2. 숫자 문자 정렬에서 정수 파싱이 필요 없는 이유는 무엇인가?
3. 2와 10이라는 문자열 목록을 정렬하는 문제도 같은 방식으로 해결할 수 있는가?

## 직접 연습과 복습

- 405040의 정렬 배열과 역순 출력을 손으로 적는다.
- 길이 1, 중복 숫자, 0 포함 입력을 테스트한다.
- [ ] 정렬 방향과 출력 방향을 구분한다.
- [ ] 역순 반복에서 인덱스 0을 포함한다.
- [ ] 문자 코드 순서를 적용할 수 있는 범위를 설명한다.
