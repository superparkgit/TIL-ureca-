# 오늘의 학습 자료 · 최댓값 초기화와 위치

최댓값을 0으로 시작하면 음수만 있는 데이터에서 실제 입력에 없는 0이 남을 수 있다. 첫 입력값이나 Integer.MIN_VALUE로 시작하면 첫 비교를 올바르게 처리할 수 있다.

직접 만든 예제 [-7, -3, -9]의 최댓값은 -3이다. 위치도 필요하면 값이 갱신되는 분기에서 인덱스를 함께 갱신한다.

핵심 질문. >를 >=로 바꾸면 동률에서 어떤 위치가 남을까?

손풀이. [4, 8, 8, 2]에 두 비교 조건을 각각 적용해 남는 인덱스를 적는다.

복습. 0부터 시작하는 내부 인덱스와 1부터 시작하는 출력 번호의 차이를 확인한다.
