# 존재 여부는 Set, 연결된 값은 Map

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

허용 단어가 red, blue라면 Set<String>에 저장하고 contains로 존재를 확인한다. red가 세 번 나왔다는 정보까지 필요하면 Map<String,Integer>에 횟수를 저장한다.

Set은 같은 원소를 여러 번 넣어도 하나로 유지한다. 그러나 조회 요청이 red, red라면 두 요청 모두 존재하므로 일치 요청 수는 2다. 저장 중복과 질문 중복은 다르다.

## 핵심 질문

1. HashSet의 크기로 질문 일치 개수를 대신할 수 없는 이유는 무엇인가?
2. app과 apple은 같은 원소인가?
3. 등장 횟수까지 필요하면 어떤 자료구조가 적합한가?

## 직접 연습과 복습

- 허용 코드 집합과 세 요청을 만들어 포함 여부를 출력한다.
- 같은 값을 두 번 add하고 size를 확인한다.
- [ ] 저장 중복과 요청 반복을 구별한다.
- [ ] 전체 문자열 비교와 부분 문자열 검사를 구분한다.
- [ ] Set과 Map 선택 이유를 한 문장으로 적는다.
