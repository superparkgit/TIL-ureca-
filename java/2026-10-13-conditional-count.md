# 조건을 만족할 때만 누적하기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 예제

목표 값 하나의 개수만 필요하면 모든 값의 빈도 배열을 만들 필요 없이 count 하나로 충분하다. [2,-1,2,5,2]에서 목표가 2일 때 count는 1,1,2,2,3으로 변한다.

int는 값 비교에 ==를 사용한다. 문자열 내용 비교는 equals를 사용한다는 차이도 복습한다.

## 핵심 질문

1. 목표가 목록 뒤에 입력되면 목록을 왜 저장해야 하는가?
2. 일치하지 않을 때 count를 0으로 바꾸면 왜 틀리는가?
3. 목표 값 하나의 개수와 모든 값의 빈도 중 현재 요구는 무엇인가?

## 직접 연습

- 배열에서 음수 개수와 짝수 개수를 각각 센다.
- [2,-1,2,5,2]를 손으로 추적한 뒤 구현한다.
- [ ] count 초기값 0을 설명한다.
- [ ] 일치·불일치에서 상태를 구분한다.
- [ ] 목표 없음과 모두 일치하는 입력을 검증한다.
