# 오늘의 학습 자료 · 큐 한 바퀴와 나머지

큐의 맨 앞을 맨 뒤로 옮기는 연산을 큐의 크기만큼 반복하면 원래 순서로 돌아온다. 예를 들어 [2, 5, 8]을 8번 회전하면 2번 회전한 [8, 2, 5]와 같다.

요세푸스 문제에서는 현재 맨 앞을 첫 번째로 세므로 K번째를 빼기 전 K-1번만 회전한다. 한 명을 뺄 때마다 큐 크기가 줄어 나머지를 다시 계산한다.

핵심 질문. K를 그대로 쓰면 누구를 건너뛰게 될까? 큐가 비었을 때 나머지 연산을 하면 어떻게 될까?

손풀이. [1, 2, 3, 4]에서 K=3일 때 각 단계의 큐 크기와 실제 회전 횟수, 제거 순서를 적는다.

복습. FIFO, 회전과 제거가 큐 크기에 주는 영향, 원소 한 개일 때의 결과를 확인한다.
