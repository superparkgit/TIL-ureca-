# 오늘의 학습 자료 · 덱의 조회와 제거

[7, 2]에서 peekLast는 2를 반환하고 상태를 유지한다. 이어서 pollLast를 호출하면 2를 반환하고 [7]이 남는다. 두 메서드 모두 빈 덱에서는 null을 반환한다. 값을 int에 바로 대입하면 null을 언박싱할 때 예외가 발생하므로 Integer로 받고 검사한다.

핵심 질문. 조회 명령을 연속 두 번 호출하면 크기가 바뀔까? poll을 쓰면 어떨까?

손풀이. 빈 덱에 addFirst(4), addLast(9), peekFirst(), pollLast(), pollFirst(), pollFirst()를 순서대로 적용한다. 각 호출의 반환값과 덱 상태를 적는다.

복습. FIFO를 구현할 때 삽입과 제거에 어느 쪽 끝을 쓰는지 설명한다.
