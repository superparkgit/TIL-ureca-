# Arrays.sort와 원본 변경

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 예제

int[] values = {3,1,2}에 Arrays.sort(values)를 호출하면 values 자체가 [1,2,3]으로 바뀐다. 새 정렬 배열을 반환받는 메서드가 아니므로 반환값을 변수에 대입하지 않는다.

원본이 필요하면 values.clone()으로 별도 배열을 만든 뒤 복사본을 정렬한다. int 배열 복사는 값을 복제하므로 복사본 정렬이 원본 순서를 바꾸지 않는다.

## 핵심 질문

1. 정렬 뒤 원래 입력 순서가 필요한 경우 무엇을 보관해야 하는가?
2. 정렬 결과가 오름차순이라는 사실만으로 원소 누락까지 검증할 수 있는가?
3. 정렬 전에 최솟값만 필요하다면 전체 정렬이 꼭 필요한가?

## 직접 연습과 복습

- [4,-2,7,0]을 정렬하고 첫·마지막 원소를 확인한다.
- 복사본만 정렬해 원본이 유지되는지 출력한다.
- [ ] 반환값과 원본 변경을 구별한다.
- [ ] 인접 원소 순서와 전체 원소 보존을 확인한다.
- [ ] 정렬 없이 한 번 순회하는 풀이와 비교한다.
