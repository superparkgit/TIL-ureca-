# Java 문자열을 문자 단위로 순회하기

> 상태: 오늘의 학습 자료 및 연습 과제

## 문자열의 길이와 문자 접근

String의 길이는 length()로 구하고, 특정 위치의 문자는 charAt(index)로 읽는다. 인덱스는 0부터 시작하므로 마지막 문자의 인덱스는 length() - 1이다.

문자열이 ABC라면 charAt(0)은 A, charAt(1)은 B, charAt(2)는 C다.

## 중첩 반복문의 역할 나누기

각 문자를 여러 번 반복하려면 두 반복문의 책임을 구분한다.

- 바깥 반복문: 문자열에서 다음 문자로 이동
- 안쪽 반복문: 현재 문자를 정해진 횟수만큼 추가

반복 횟수가 3이고 문자열이 AB라면 A를 세 번 추가한 뒤 B를 세 번 추가해 AAABBB를 만든다.

## StringBuilder를 사용하는 이유

String은 변경할 수 없는 객체이므로 반복문에서 더하기 연산으로 계속 이어 붙이면 중간 문자열 객체가 많이 생길 수 있다. StringBuilder는 내부 버퍼에 문자를 누적하고 마지막에 문자열로 바꾸므로 반복 출력에 알맞다.

## char와 String 구분

charAt의 반환값은 문자 하나를 나타내는 char다. String은 문자 여러 개를 담는 문자열이다. 문자 한 개를 StringBuilder에 추가할 때는 char를 그대로 append할 수 있다.

## 핵심 질문

1. 길이가 5인 문자열의 마지막 인덱스는 무엇인가?
2. 문자열 전체를 3번 반복하는 것과 각 문자를 3번 반복하는 결과는 어떻게 다른가?
3. 반복문 안에서 String 더하기보다 StringBuilder가 적합한 이유는 무엇인가?

## 직접 연습

1. 문자열의 각 문자를 한 줄씩 출력한다.
2. hello를 뒤에서 앞으로 순회해 출력한다.
3. 문자와 반복 횟수를 받아 반복 문자열을 만드는 메서드를 작성한다.

## 복습 체크

- [ ] 유효한 인덱스 범위를 설명한다.
- [ ] 중첩 반복문의 역할을 문장으로 나눈다.
- [ ] 여러 테스트 케이스의 줄바꿈을 확인한다.
