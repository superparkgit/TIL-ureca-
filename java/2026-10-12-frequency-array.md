# 등장 여부에서 등장 횟수로: 빈도 배열

> 오늘의 학습 자료·연습 과제. 사용자 학습 완료 기록은 아니다.

## 개념과 예제

boolean 배열은 한 번이라도 등장했는지만 기억한다. 횟수가 필요하면 int 배열의 해당 칸을 증가시킨다.

문자열 20220의 빈도는 0이 2번, 2가 3번이다. 문자에서 '0'을 빼면 숫자 0~9를 인덱스로 사용할 수 있다. 입력이 숫자 문자일 때만 유효하다.

모든 빈도를 더하면 입력 길이 5가 되어야 한다. 이 조건으로 집계 누락을 검산할 수 있다.

## 핵심 질문

1. boolean 배열로 2가 세 번 등장했다는 정보를 표현할 수 있는가?
2. 문자 '2'와 숫자 2는 어떻게 다른가?
3. 빈도 합과 입력 길이가 다르면 어떤 오류를 의심할까?
