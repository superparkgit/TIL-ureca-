# 오늘의 학습 자료 · 반복문 상태의 범위

단어별 방문 배열은 단어 반복문 안에서 생성한다. 바깥에서 하나만 공유하면 앞 단어의 방문 이력이 다음 단어에 섞일 수 있다.

직접 만든 예제에서 "ab" 다음 "ba"를 검사해도 두 단어는 각각 유효하다. 한 단어 안의 "aba"는 a가 끊겼다가 다시 등장한다.

핵심 질문. 직전 문자와 방문 이력은 각각 어떤 정보를 기억할까?

손풀이. "aabbaa"에서 문자가 바뀌는 위치와 방문 배열의 상태를 적는다.

복습. 연속 중복과 떨어진 재등장을 구별하고 단어별 초기화 위치를 확인한다.
