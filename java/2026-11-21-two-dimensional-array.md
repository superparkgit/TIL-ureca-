# 오늘의 학습 자료 · 2차원 배열의 행과 열

new int[2][3]은 두 행에 각각 세 칸을 만든다. a.length는 2, a[0].length는 3이다. int 원소의 초기값은 0이므로 합계를 누적할 수 있다.

직접 만든 예제에서 a[1][2] = 8은 두 번째 행의 세 번째 칸에 8을 저장한다.

핵심 질문. 행 수와 열 수가 같을 때만 테스트하면 어떤 인덱스 실수를 놓칠까?

손풀이. 2×3 배열에 1부터 6까지 행 순서로 채우고 a[0][2], a[1][0]의 값을 적는다.

복습. 유효 인덱스는 길이보다 작다는 조건과 중첩 반복문의 실행 횟수를 설명한다.
