# 정렬된 배열에서 이진 탐색하기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

정렬 배열 [2,5,8,11,14]에서 11을 찾는다. 가운데 8보다 11이 크므로 8 이하 구간을 버린다. 남은 [11,14]의 가운데에서 11을 찾는다.

닫힌 구간은 left와 right를 모두 포함한다. left가 right보다 커지면 후보가 없다. 불일치 시 middle+1 또는 middle-1로 이동해야 이미 검사한 가운데가 다시 남지 않는다.

## 핵심 질문

1. 정렬되지 않은 배열에서 절반을 버리면 왜 위험한가?
2. left=middle로 갱신하면 어떤 입력에서 끝나지 않을 수 있는가?
3. 원소가 하나 남았을 때도 검사하려면 반복 조건은 무엇인가?

## 직접 연습과 복습

- [2,5,8,11,14]에서 2,14,7을 찾는 구간을 종이에 적는다.
- 같은 질문을 순차 탐색으로 풀어 결과를 비교한다.
- [ ] 정렬 선행 조건을 설명한다.
- [ ] 반복마다 후보 구간이 줄어드는지 확인한다.
- [ ] 첫 값·끝 값·없는 값·원소 1개를 검증한다.
