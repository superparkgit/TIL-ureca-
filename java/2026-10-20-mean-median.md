# 평균과 중앙값의 계산 순서

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

[10,20,30,40,90]의 평균은 38이고 중앙값은 30이다. 평균은 모든 값을 합산하고 개수로 나누며, 중앙값은 정렬 후 가운데 위치를 읽는다.

홀수 길이 N인 배열은 정렬 후 N/2 인덱스가 가운데다. 짝수 길이는 가운데 두 값의 평균을 쓰는 정의가 흔하므로 문제의 요구를 먼저 확인한다.

평균은 입력 순서와 무관하다. 중앙값을 위치로 읽으려면 정렬이 필요하다. Arrays.sort는 원본 배열을 바꾸므로 원래 순서가 필요하면 복사본을 정렬한다.

## 핵심 질문

1. 정렬 전 가운데 원소를 중앙값이라 부를 수 없는 이유는 무엇인가?
2. 큰 값 하나를 더 크게 바꾸면 평균과 중앙값은 각각 어떻게 달라질까?
3. 일반 정수 목록 평균에서 정수 나눗셈을 쓰면 어떤 정보가 사라질까?

## 직접 연습과 복습

- [3,1,100,2,4]의 평균과 중앙값을 손으로 계산한다.
- 중복 원소가 있는 목록으로 정렬·가운데 인덱스를 확인한다.
- [ ] 평균과 중앙값을 구분한다.
- [ ] 정렬 후 가운데 인덱스를 계산한다.
- [ ] 나눗셈 결과가 정수인지 확인한다.
