# 오늘의 학습 자료: 큐 회전과 반복문 불변식

사용자 학습 완료 기록이 아닌 참고 자료와 연습 과제다.

`[2, 4, 6]`에서 `addLast(removeFirst())`를 실행하면 `[4, 6, 2]`가 된다. 삭제 후 다시 넣으므로 원소 수는 그대로이며 상대 순서가 순환한다. `removeFirst()`는 빈 덱에서 예외를 발생시키므로 마지막 원소를 버린 뒤 회전할 때는 비었는지 먼저 확인한다.

## 핵심 질문
- 회전만 하는 반복은 왜 종료를 보장하지 못할까?
- 매 반복마다 카드 한 장을 버린다면 반복 횟수가 왜 최초 카드 수와 같을까?
- `[3]`에서 버리기 후 회전을 시도하면 어떤 문제가 생길까?

## 직접 만든 연습
`[1, 2, 3, 4, 5]`에서 버리기와 회전을 번갈아 수행하고, 매 단계의 큐와 버린 값을 표로 작성한다. 반복 시작 시 큐에는 아직 버리지 않은 카드가 현재 순서대로 들어 있다는 성질이 유지되는지 확인한다.

복습: FIFO와 스택 LIFO 비교, 조회와 삭제 차이, 빈 큐 처리. 완료 여부는 직접 풀이를 확인한 뒤 기록한다.
