# 문자 코드와 숫자 값 구별하기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

char digit = '7'일 때 (int) digit은 55, digit - '0'은 7이다. 전자는 문자 코드, 후자는 숫자 문자가 나타내는 값이다.

Java char는 UTF-16 코드 단위다. ASCII 범위 영문·숫자의 값은 ASCII와 같지만 모든 문자를 ASCII라고 부르면 정확하지 않다. 일부 문자는 char 두 개로 표현된다.

숫자 변환에서 '0'을 빼는 방식은 입력이 '0'~'9'임을 확인한 뒤 사용한다. 임의 문자가 들어올 수 있는 프로그램에서는 범위 검사가 필요하다.

## 핵심 질문

1. '0'을 int로 바꾸면 왜 0이 아닌가?
2. ASCII 문자 코드와 숫자 값 중 요구하는 것이 무엇인가?
3. 임의 문자에서 '0'을 빼면 숫자 변환이라고 할 수 있는가?

## 연습과 복습

- '3'의 코드와 숫자 값을 각각 예측하고 실행한다.
- 'A'에서 'a'를 빼는 결과를 실행해 확인한다.
- [ ] 입력의 문자 범위를 확인한다.
- [ ] 코드 변환과 숫자 변환을 구별한다.
- [ ] 문자열 파싱과 char 계산의 차이를 설명한다.
