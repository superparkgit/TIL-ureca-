# 조회용 Set과 출력용 List 조합하기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

첫 목록 [red,blue,green], 둘째 [green,red,black]의 공통값을 찾으면 입력 중에는 green,red 순서로 모인다. 출력 요구가 사전순이면 별도 정렬해 green,red를 출력한다. 입력 순서가 red,green이어도 최종 정렬 결과는 같다.

HashSet은 빠른 포함 조회, ArrayList는 결과 보관, Collections.sort는 출력 순서 정리를 담당한다. 자료구조 하나에 모든 역할을 맡길 필요는 없다.

일반 데이터에 중복이 허용되면 결과 중복 제거 정책을 먼저 정한다. 문제 조건이 중복을 금지한 경우에만 단순 목록 추가가 집합 교집합과 일치한다.

## 핵심 질문

1. HashSet을 그대로 순회해 사전순 출력을 기대할 수 있는가?
2. 입력 중복이 허용되면 결과에 어떤 변화가 생기는가?
3. 개수만 필요하면 결과 목록과 정렬이 필요한가?

## 직접 연습과 복습

- 두 문자열 목록의 교집합을 구해 정렬한다.
- 공통 없음·전부 공통·입력 순서 역순을 확인한다.
- [ ] 포함 조회와 출력 순서를 분리한다.
- [ ] 중복 허용 조건을 확인한다.
- [ ] 결과 개수와 출력 줄 수가 일치하는지 확인한다.
