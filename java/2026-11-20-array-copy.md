# 오늘의 학습 자료 · 배열 복사와 참조

int[] a = {3, 6, 9}에서 int[] b = a를 실행하면 두 변수가 같은 배열을 참조한다. b[0] = 7을 실행하면 a[0]도 7이다. a.clone()으로 만든 int 배열은 원소 값을 별도 배열에 복사한다.

핵심 질문. 회전 중 원본에 바로 덮어쓰면 아직 읽지 않은 값은 어떻게 될까?

손풀이. [1, 2, 3, 4]를 [3, 4, 1, 2]로 바꿀 때 임시 배열의 각 인덱스에 어떤 값을 넣는지 적는다. 위 참조 예제도 직접 실행해 예측과 비교한다.

복습. ==의 참조 비교, 배열 인덱스 경계, System.arraycopy의 원본·대상 인자를 확인한다.
