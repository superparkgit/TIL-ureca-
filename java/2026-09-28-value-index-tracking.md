# 값과 인덱스를 함께 추적하기

- 날짜: 2026-09-28
- 상태: 오늘의 학습 자료·연습 과제
- 연계 문제: [백준 2562 최댓값](https://www.acmicpc.net/problem/2562)

## 1. 값만으로는 부족한 문제

최댓값만 묻는다면 변수 하나로 충분하다. 하지만 최댓값이 등장한 위치도
필요하면 값과 위치를 하나의 상태처럼 함께 갱신해야 한다.

```java
int maximum = Integer.MIN_VALUE;
int maximumIndex = -1;

for (int index = 0; index < numbers.length; index++) {
    if (numbers[index] > maximum) {
        maximum = numbers[index];
        maximumIndex = index;
    }
}
```

최댓값만 바꾸고 인덱스를 바꾸지 않으면 서로 관련 없는 값과 위치가 남는 버그가
생긴다.

## 2. 배열 인덱스와 문제의 순서

Java 배열 인덱스는 `0`부터 시작하지만 문제에서 말하는 첫 번째 위치는 보통
`1`이다. 두 기준을 섞지 않도록 다음 중 하나를 일관되게 사용한다.

- 내부에서는 0부터 세고 출력할 때 `index + 1`을 한다.
- 반복 변수 자체를 1부터 시작하고 입력값을 즉시 처리한다.

## 3. 동점 처리 기준

같은 최댓값이 여러 번 등장할 수 있다면 비교 연산자에 따라 결과가 달라진다.

```java
if (number > maximum) {   // 첫 번째 최댓값 위치 유지
    // 갱신
}

if (number >= maximum) {  // 마지막 최댓값 위치 유지
    // 갱신
}
```

코드를 작성하기 전에 첫 번째 위치와 마지막 위치 중 무엇을 요구하는지 확인해야
한다.

## 4. 값과 위치를 묶는 방법

추적할 정보가 많아지면 별도 클래스로 묶을 수 있다.

```java
record MaxResult(int value, int index) {
}
```

간단한 문제에서는 변수 두 개가 읽기 쉽지만, 여러 메서드 사이에서 결과를
전달한다면 작은 객체가 의미를 더 명확하게 만들 수 있다.

## 핵심 질문

1. 최댓값이 바뀔 때 인덱스도 반드시 함께 바꿔야 하는 이유는 무엇인가?
2. 배열 인덱스와 문제의 위치 번호는 어떻게 다를 수 있는가?
3. `>`와 `>=`는 동점에서 각각 어떤 위치를 남기는가?
4. 변수 두 개 대신 결과 객체를 사용하는 편이 좋은 상황은 언제인가?
