# 연속 상태와 누적 결과 분리하기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

연속 성공 길이와 전체 점수는 서로 다른 상태다. OO XO를 공백 없이 처리하면 연속 길이는 1,2,0,1이고 총점은 1,3,3,4다. 실패에서 연속 길이만 초기화하고 과거 총점은 보존한다.

여러 테스트를 처리할 때 streak와 total을 케이스 반복문 내부에서 선언하면 각 케이스가 0부터 시작한다. 선언 위치는 상태가 살아 있어야 하는 범위와 맞춰야 한다.

## 핵심 질문

1. 실패에서 total을 0으로 바꾸면 무엇이 사라지는가?
2. streak를 케이스 밖에 선언하고 초기화를 빠뜨리면 어떤 문제가 생기는가?
3. 누적 결과와 현재 연속 길이를 하나의 변수로 관리할 수 있는가?

## 직접 연습과 복습

- OOXOOO의 streak와 total을 문자마다 표로 적는다.
- 배열에서 연속 양수의 최대 길이를 찾는다.
- [ ] 실패 시 초기화할 변수만 고른다.
- [ ] 케이스 경계에서 상태를 초기화한다.
- [ ] 전부 실패·전부 성공·길이 1을 확인한다.
