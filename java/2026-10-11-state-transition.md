# 상태가 바뀌는 순간 세기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

단어 수를 셀 때 문자 개수나 공백 개수보다 단어 밖에서 안으로 들어가는 순간을 세면 경계를 정확히 처리할 수 있다.

입력 '  hi there '에서 처음 두 공백은 밖 상태를 유지한다. h에서 첫 단어가 시작되고 i는 같은 단어 안이므로 증가시키지 않는다. 다음 공백에서 밖으로 나가고 t에서 두 번째 단어를 센다.

상태는 boolean inWord로 저장한다. 공백은 false로 바꾸고, 공백이 아닌 문자와 false 상태가 함께 나타나면 count를 증가시킨 뒤 true로 바꾼다.

## 핵심 질문

1. 공백 수에 1을 더하는 방식은 앞뒤 공백에서 왜 틀리는가?
2. 모든 문자마다 count를 올리면 무엇을 세게 되는가?
3. 탭도 구분자로 처리하는 일반 프로그램이라면 어떤 조건을 바꿔야 하는가?

## 연습과 복습

- '  red blue  '의 상태와 count를 문자마다 적는다.
- 공백만 있는 입력과 한 단어를 테스트한다.
- [ ] 상태와 사건을 구별한다.
- [ ] 단어 시작에서만 개수를 올린다.
- [ ] readLine과 공백 단위 입력의 차이를 설명한다.
