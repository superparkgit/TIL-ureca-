# 순위를 배열 인덱스로 바꾸기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

오름차순 [10,20,30,40]에서 두 번째로 작은 값은 인덱스 1, 두 번째로 큰 값은 인덱스 2다. 길이 N에서 k번째 작은 값은 k-1, k번째 큰 값은 N-k다.

동점 값도 원소마다 순위 자리를 차지한다. 서로 다른 값만 세는 순위가 필요하다면 중복 제거라는 별도 요구가 필요하다.

## 핵심 질문

1. N-k-1을 쓰면 어떤 순위가 나오는가?
2. k=1과 k=N에서 인덱스는 각각 무엇인가?
3. 동점 포함 순위와 서로 다른 값 기준 순위는 어떻게 다른가?

## 직접 연습과 복습

- [7,2,9,9,4]에서 1·3·5번째 큰 값을 손으로 찾는다.
- 오름차순 정렬로 k번째 작은 값을 출력하도록 바꾼다.
- [ ] 정렬 방향을 먼저 적는다.
- [ ] 순위와 인덱스의 시작값을 구분한다.
- [ ] 양끝 순위와 동점 입력을 테스트한다.
