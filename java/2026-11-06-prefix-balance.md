# 스택 대신 개수로 괄호 판정하기

> 오늘의 학습 자료·연습 과제

소괄호만 있으면 스택에서 꺼낼 원소의 종류가 항상 같으므로 미해결 개수만 기억해도 된다.
예를 들어 (()())의 변화는 1, 2, 1, 2, 1, 0이다.
반면 )(는 최종 합이 0이어도 첫 단계에서 짝을 찾을 수 없다.

핵심 질문: ([)]의 개수도 마지막에는 0인데 왜 여러 종류라면 스택이 필요한가?
손풀이: (())(), ())(()의 개수 변화를 적고 처음 실패하는 위치를 찾는다.
복습: 처리 중 음수 금지와 마지막 0 조건을 각각 한 문장으로 설명한다.
