# 오늘의 학습 자료 · 영문 문자와 배열 인덱스

문제 입력이 영문 알파벳일 때 대문자로 통일한 뒤 letter - 'A'로 인덱스를 구할 수 있다. 'A'는 0, 'Z'는 25가 된다. 숫자값을 상수로 외우는 대신 기준 문자를 코드에 적으면 의도가 드러난다.

직접 만든 예제 "bBa"는 B 두 번, A 한 번으로 집계한다.

핵심 질문. 대소문자 통일을 생략하면 소문자의 인덱스는 0~25에 들어갈까?

손풀이. "aAbbC"의 빈도 배열에서 0이 아닌 항목을 적고 최다 빈도 동률 여부를 판단한다.

복습. char 산술의 int 결과, 배열 범위, 최댓값 갱신과 동률 처리를 설명한다.
