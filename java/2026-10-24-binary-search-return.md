# Arrays.binarySearch 반환값 읽기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

정렬 배열 [2,5,8]에서 2를 찾으면 인덱스 0을 반환한다. 따라서 존재 조건은 반환값 >= 0이다.

없는 값은 -(삽입 위치)-1을 반환한다. 4의 삽입 위치는 1이므로 반환값은 -2다. 찾지 못한 결과가 항상 -1이라고 가정하면 안 된다.

중복 값이 있으면 어떤 중복 인덱스를 반환할지는 보장되지 않으므로 첫 위치나 개수 계산에 그대로 쓰면 안 된다.

## 핵심 질문

1. 반환값 > 0은 어떤 정상 결과를 놓치는가?
2. 1,4,9를 찾을 때 삽입 위치와 반환값은 각각 무엇인가?
3. 정렬 없이 호출하면 결과를 신뢰할 수 있는가?

## 직접 연습과 복습

- [2,5,8]에서 2,4,9의 반환값을 예측하고 실행한다.
- 어제 직접 구현한 탐색과 존재 결과를 비교한다.
- [ ] 정렬 선행 조건을 확인한다.
- [ ] 인덱스 0도 성공으로 처리한다.
- [ ] 없는 값의 음수 반환을 모두 실패로 처리한다.
