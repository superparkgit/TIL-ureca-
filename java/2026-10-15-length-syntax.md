# 배열 length와 문자열 length()

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

int[] values = {4, 8, 12}에서 values.length는 3이다. String text = "hello"에서 text.length()는 5다. 배열의 길이는 필드, 문자열의 길이는 메서드로 읽는다.

컬렉션의 원소 개수는 size()로 읽는다. 사용 중인 자료형을 먼저 확인하면 문법을 구별하기 쉽다.

String.length()는 UTF-16 코드 단위 개수다. 영문자 hello는 5지만 일부 이모지는 화면에 하나로 보여도 2가 될 수 있다. 일반 사용자 표시 문자 수를 처리할 때는 요구사항을 별도로 확인한다.

## 핵심 질문

1. 배열에 length()를 쓰거나 문자열에 length를 쓰면 왜 오류가 나는가?
2. 길이가 5인 문자열의 마지막 인덱스는 무엇인가?
3. 문자열 길이와 화면에 보이는 문자 수가 항상 같은가?

## 직접 연습과 복습

- 배열과 문자열을 각각 만들고 길이를 출력한다.
- 길이가 1인 문자열의 첫·마지막 인덱스를 적는다.
- [ ] length와 length()를 구별한다.
- [ ] 마지막 인덱스는 길이에서 1을 뺀 값임을 설명한다.
- [ ] 허용 문자 범위를 먼저 확인한다.
