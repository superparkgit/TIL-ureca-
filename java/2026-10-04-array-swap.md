# 배열의 두 값을 안전하게 교환하기

> 상태: 오늘의 학습 자료 및 연습 과제

## 왜 임시 변수가 필요한가

배열의 first 위치와 second 위치를 바꾼다고 가정한다. 먼저 array[first]에 array[second]를 대입하면 first의 원래 값이 사라진다. 사라지기 전에 temporary에 보관하고, second에 temporary 값을 넣어야 한다.

세 문장을 실행한 뒤 두 값의 위치만 달라지고 값 자체는 보존된다.

## 손으로 상태 추적하기

초기 배열이 [1, 2, 3, 4]이고 1번과 3번 위치를 교환한다면 다음처럼 추적한다.

1. temporary에 1을 보관한다.
2. 1번 위치에 3을 넣어 [3, 2, 3, 4]가 된다.
3. 3번 위치에 temporary의 1을 넣어 [3, 2, 1, 4]가 된다.

중간 상태에는 3이 두 개처럼 보이지만, 임시 변수에 1이 안전하게 보관되어 있다.

## 교환 뒤에도 유지되는 성질

- 배열 길이는 바뀌지 않는다.
- 각 값의 등장 횟수는 바뀌지 않는다.
- 같은 두 위치를 연속 두 번 교환하면 원래 상태로 돌아온다.
- 같은 위치를 자기 자신과 교환하면 아무 변화가 없다.

이런 성질은 테스트의 기대 결과를 만드는 데 사용할 수 있다.

## 핵심 질문

1. 임시 변수 없이 두 줄의 대입만 하면 어떤 값을 잃게 되는가?
2. 같은 두 위치를 두 번 교환하면 원상 복구되는 이유는 무엇인가?
3. 교환 전후에 값의 합이 같다는 사실만으로 구현이 정확하다고 확신할 수 있는가?

## 직접 연습

1. [10, 20, 30, 40]의 2번과 4번 위치를 교환한다.
2. 1번과 3번을 바꾼 뒤 다시 1번과 3번을 바꾸고 상태를 적는다.
3. 문자 배열에서 두 문자를 바꾸는 메서드를 작성한다.

## 복습 체크

- [ ] 세 단계 교환을 보지 않고 작성한다.
- [ ] 각 대입 직후 배열과 임시 변수 상태를 적는다.
- [ ] 자기 자신 교환과 두 번 교환을 테스트한다.
- [ ] 교환 전후 유지되어야 할 성질을 두 가지 말한다.
