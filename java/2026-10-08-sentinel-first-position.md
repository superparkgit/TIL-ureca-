# 미등장 상태와 첫 위치 기록

> 오늘의 학습 자료·연습 과제. 사용자 학습 완료를 의미하지 않는다.

## 초기값은 의미를 가져야 한다

int 배열의 기본값은 0이다. 그러나 문자열의 첫 문자 위치도 0이므로 기본값만으로는 미등장과 첫 위치를 구분할 수 없다. 유효 위치가 0 이상이라면 -1을 미등장 표시로 선택할 수 있다. 이런 특수 상태 값을 센티널이라고 한다.

## 직접 만든 예제

단어 cabca를 처리하면 c=0, a=1, b=2다. c가 위치 3에서 다시 등장해도 이미 기록되어 있으므로 값을 갱신하지 않는다.

```java
int[] first = new int[26];
java.util.Arrays.fill(first, -1);
String word = "cabca";
for (int i = 0; i < word.length(); i++) {
    int letter = word.charAt(i) - 'a';
    if (first[letter] == -1) first[letter] = i;
}
```

문제 입력이 영문 소문자일 때만 이 26칸 매핑이 유효하다. 일반 문자열 처리에서는 허용 문자 범위를 먼저 정해야 한다.

## 핵심 질문

1. 초기값 0을 사용하면 어떤 두 상태가 섞이는가?
2. 조건을 제거하고 매번 대입하면 첫 위치와 마지막 위치 중 무엇이 남는가?
3. -1도 유효 데이터라면 미설정 상태를 어떻게 표현할까?

## 연습과 복습

- cabca의 처리 과정을 종이에 5행으로 적는다.
- 각 문자의 마지막 위치를 구하는 코드로 바꾼다.
- [ ] 첫 위치 0과 미등장 상태를 구별해 설명한다.
- [ ] 반복 문자 입력에서 첫 위치가 보존되는지 확인한다.
