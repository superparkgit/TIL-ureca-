# 배열 구간 갱신과 덮어쓰기

> 상태: 오늘의 학습 자료 및 연습 과제

## 구간 갱신이란

배열의 시작 위치부터 끝 위치까지 같은 값을 넣는 작업이다. 예를 들어 2번부터 4번까지 값 7을 넣는다면 2, 3, 4번 원소를 각각 7로 바꾼다.

중요한 점은 끝 위치도 포함한다는 것이다. 반복 조건을 index &lt; end로 쓰면 마지막 칸이 빠지고, index &lt;= end로 써야 모두 갱신된다.

## 기본값 활용

Java에서 새로 만든 int 배열의 모든 원소는 0이다. 따라서 0이 '아직 값이 없음'을 뜻하는 문제라면 별도의 초기화가 필요 없다.

단, 0도 정상 데이터인 문제에서는 값 0과 미설정 상태를 구별할 수 없다. 그때는 별도의 boolean 배열이나 다른 초기값이 필요하다.

## 덮어쓰기와 누적의 차이

- 덮어쓰기: values[index] = newValue
- 누적: values[index] += amount

문제에서 '새 공으로 바꾼다'면 덮어쓰기이고, '공을 추가한다'면 누적일 수 있다. 연산자를 정하기 전에 상태 변화 문장을 먼저 확인한다.

## 1번 기반 번호와 배열

번호가 1부터 N까지라면 길이가 N + 1인 배열을 만들고 0번 칸을 비워둘 수 있다. 값과 인덱스가 같아 코드가 읽기 쉬워지지만, 0번 칸을 출력하지 않도록 주의한다.

## 핵심 질문

1. 구간 [2, 4]를 처리할 때 반복문은 몇 번 실행되어야 하는가?
2. 두 명령의 범위가 겹치면 겹친 칸의 최종 값은 무엇이 결정하는가?
3. int 배열의 기본값 0을 미설정 상태로 쓰면 안 되는 경우는 언제인가?

## 직접 연습

1. 길이 6인 배열의 2~5번을 3으로 바꾼다.
2. 같은 배열의 4~6번을 다시 8로 바꾸고 최종 상태를 적는다.
3. 덮어쓰기 코드를 누적 코드로 바꾼 뒤 결과 차이를 설명한다.

## 복습 체크

- [ ] 시작과 끝을 모두 포함하는 반복 조건을 작성한다.
- [ ] 덮어쓰기와 누적을 구분한다.
- [ ] 사용하지 않는 0번 인덱스를 출력에서 제외한다.
- [ ] 겹치는 구간의 최종 상태를 손으로 추적한다.
