# ArrayDeque로 스택 다루기

오늘의 학습 자료·연습 과제이며 사용자 학습 완료를 뜻하지 않는다.

4와 7을 차례로 push하면 top은 7이다. peek는 7을 보고 두 원소를 유지하고, pop은 7을 제거해 4만 남긴다. 빈 상태에서 pop을 호출하면 예외가 나므로 문제의 빈 값 정책을 먼저 적용한다.

핵심 질문: peek와 pop의 반환값이 같아도 상태는 어떻게 다른가? push와 pop을 같은 끝에서 처리해야 하는 이유는 무엇인가?

연습: 4 push → 7 push → peek → pop → size의 반환값과 상태를 손으로 적는다. 빈 스택과 한 원소를 검증한다.
