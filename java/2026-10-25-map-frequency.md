# HashMap으로 빈도 집계하기

> 오늘의 학습 자료·연습 과제. 사용자 완료 기록은 아니다.

## 개념과 직접 만든 예제

카드 [-2,7,-2]를 집계하면 키 -2의 값은 2, 키 7의 값은 1이다. getOrDefault(key,0)은 키가 없을 때 0을 돌려주므로 첫 등장도 같은 식으로 처리할 수 있다.

빈도를 증가시키려면 put(value, getOrDefault(value,0)+1)을 사용한다. 단순 조회는 getOrDefault만 호출한다. 조회할 때 값을 갱신하면 질문 반복에 따라 결과가 달라질 수 있다.

좁고 고정된 범위는 배열, 넓거나 음수가 포함된 범위는 Map을 고려한다. HashMap은 순서를 보장하지 않으므로 질문 순서대로 조회해 출력한다.

## 핵심 질문

1. 첫 등장과 재등장을 같은 식으로 처리할 수 있는 이유는 무엇인가?
2. 같은 질문을 두 번 해도 빈도가 유지되어야 하는 이유는 무엇인가?
3. HashMap 순회 순서에 출력 순서를 맡기면 왜 위험한가?

## 직접 연습과 복습

- [-1,4,4,-1,4]를 손으로 집계하고 코드와 비교한다.
- 없는 키·반복 질문을 테스트한다.
- [ ] 키와 값의 의미를 적는다.
- [ ] 집계와 조회를 구분한다.
- [ ] 모든 빈도의 합이 입력 개수인지 확인한다.
