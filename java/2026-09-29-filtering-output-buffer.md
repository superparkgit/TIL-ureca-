# 조건 필터링과 출력 버퍼

- 날짜: 2026-09-29
- 상태: 오늘의 학습 자료·연습 과제
- 연계 문제: [백준 10871 X보다 작은 수](https://www.acmicpc.net/problem/10871)

## 1. 필터링이란

필터링은 여러 값 가운데 조건을 만족하는 값만 선택하는 과정이다.

```java
for (int number : numbers) {
    if (number < limit) {
        // 조건을 통과한 값만 처리한다.
    }
}
```

이 문제에서는 원래 입력 순서를 유지해야 하므로 값을 정렬하거나 위치를 바꾸면
안 된다.

## 2. `<`와 `<=` 구분하기

- `number < limit`: 기준값과 같은 값은 제외한다.
- `number <= limit`: 기준값과 같은 값도 포함한다.

문제의 “보다 작은”과 “이하”를 정확히 구분하고, `number == limit`인 경계값을
테스트해야 한다.

## 3. 출력을 모아서 처리하기

반복문에서 매번 출력하면 출력 호출 횟수가 많아진다. `StringBuilder`에 결과를
모은 뒤 한 번에 출력하면 출력 형식을 제어하기 쉽다.

```java
StringBuilder result = new StringBuilder();

for (int number : numbers) {
    if (number < limit) {
        if (result.length() > 0) {
            result.append(' ');
        }
        result.append(number);
    }
}

System.out.println(result);
```

## 4. 결과가 비어 있는 경우

조건을 만족하는 값이 하나도 없을 수 있다. 이때 `StringBuilder`는 빈 문자열이며
`println()`으로 출력하면 빈 줄 하나가 만들어진다. 임의의 안내 문구나 `0`을
출력해서는 안 된다.

## 핵심 질문

1. 필터링과 정렬은 어떻게 다른가?
2. `<`와 `<=`의 차이를 어떤 입력으로 테스트할 수 있는가?
3. `StringBuilder`를 출력 버퍼로 사용하면 어떤 점이 편리한가?
4. 조건을 통과한 값이 없을 때 무엇을 출력해야 하는가?

## 직접 해볼 연습

1. 배열에서 짝수만 입력 순서대로 출력한다.

3. 첫 번째 값 앞과 마지막 값 뒤에는 공백이 없도록 출력한다.
4. 백준 10871을 보지 않고 다시 작성한다.
