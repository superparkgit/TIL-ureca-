# Java 정수 나눗셈과 실수 연산

> 상태: 오늘의 학습 자료 및 연습 과제

## 정수끼리 나누면 생기는 일

Java에서 int끼리 나누면 결과도 int다. 3 / 2는 1.5가 아니라 소수 부분이 버려진 1이 된다. 결과를 나중에 double 변수에 넣어도 이미 손실된 소수 부분은 돌아오지 않는다.

예를 들어 double result = 3 / 2의 result는 1.0이다.

## 실수 연산으로 바꾸기

피연산자 중 하나를 double로 만들면 나눗셈 전체가 실수 연산이 된다.

- 3.0 / 2는 1.5
- (double) 3 / 2는 1.5
- double 변수에 저장된 3을 2로 나누면 1.5

형 변환은 나눗셈이 끝난 뒤가 아니라 나눗셈 전에 적용해야 한다.

## 연산 순서 확인하기

sum / maximum × 100 / count 같은 식에서는 sum이 double이면 뒤의 연산도 실수로 이어진다. 반대로 모든 변수가 int라면 첫 나눗셈에서 값이 잘릴 수 있다.

정확성이 필요한 식은 간단한 숫자를 넣어 예상값과 비교한다. sum = 3, maximum = 2라면 첫 계산 결과가 1.5여야 한다.

## 불필요한 배열 피하기

평균을 구하는 데 합계와 개수만 필요하다면 모든 값을 배열에 보관할 필요가 없다. 변환된 각 값을 나중에 다시 사용하지 않는다면 합계와 최댓값만 유지해 공간과 코드 복잡도를 줄일 수 있다.

## 핵심 질문

1. double result = 1 / 2의 결과가 0.0인 이유는 무엇인가?
2. (double) (1 / 2)와 (double) 1 / 2는 왜 결과가 다른가?
3. 평균 계산에서 배열 없이도 해결 가능한 조건은 무엇인가?

## 직접 연습

3. 점수 배열의 합계와 최댓값을 한 번의 순회로 구한다.
