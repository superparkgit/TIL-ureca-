# 오늘의 학습 자료 · 문자열 길이와 접근 범위

문자열 "CAT"의 length()는 3이고 charAt에 전달할 수 있는 인덱스는 0, 1, 2다. 길이가 다른 문자열들을 같은 열로 읽을 때는 각 문자열의 길이를 따로 검사한다.

직접 만든 예제 ["AB", "C"]의 세로 읽기 결과는 ACB다. 두 번째 행에는 열 1의 문자가 없다.

핵심 질문. 전체 최대 길이만 확인하면 짧은 행에서도 안전할까?

손풀이. ["12", "3", "456"]의 열별 접근과 최종 출력 순서를 적는다.

복습. 행·열 반복 순서를 바꿨을 때 방문 순서와 유효 인덱스를 확인한다.
