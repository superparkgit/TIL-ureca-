# 큐와 스택의 제거 순서

> 오늘의 학습 자료·연습 과제

4,7을 차례로 넣으면 큐는 4를 먼저 꺼내고 스택은 7을 먼저 꺼낸다.
ArrayDeque를 큐로 쓰려면 addLast로 넣고 removeFirst로 꺼낸다. peekFirst와 peekLast는 조회만 한다.

핵심 질문: front 조회를 반복해도 크기가 같은 이유는 무엇인가? 스택 메서드 push/pop을 섞으면 순서가 어떻게 달라지는가?
손풀이: 4 삽입 → 7 삽입 → front → pop → back의 반환값과 남은 상태를 적는다.
